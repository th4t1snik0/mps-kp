## A. Схема Э3 и перечень

### A.0. Главное
1. А3 альбомный, рамка заполнена (ФИО, дата, «Группа …, Вариант …, Э3»). Сдача PNG, «Фамилия ИО Схема-v1.png», тема «МПС-Схема», JPG нельзя. К КМ-2 схема готова к печати — её подписывают и несут на защиту (ТЗ-2025). [!] в типовых замечаниях «А1» — устарело.
2. Только чёрно-белое.
3. Позиционные обозначения у всех элементов, сверху/слева. Нумерация сверху вниз по столбцам слева направо (методичка допускает и иначе — выбрать одно).
4. Номера выводов у всех микросхем; имена выводов прижаты к ножкам («не в такт» — замечание). Части одного корпуса (DD7.1/DD7.2) — разные номера выводов.
5. Шины: вход и ветвление только Т-образно с именем линии в каждой точке входа; пересечение = нет контакта, без «мостиков»; точки на ветвлениях проводников обязательны («не везде стоят точки»), на шинах не ставятся; число линий не пишут; имя шины Bx; шина жирная, проводник тонкий.
6. Имена глобальных сигналов над проводниками. Все CS и стробы активны нулём, с чертой.
7. Третье состояние единообразно (Z или ромб).
8. Питание/земля у всех корпусов; для мелкой логики, неиспользуемых входов (к GND/VCC) и размещения конденсаторов — текстовое «Примечание» над штампом.
9. Разъёмы: питание, X, Y, доступ к буферу (правый порт + строб X2). В каждом GND. Таблица «Контакт/Цепь».
10. Фильтры: 68 нФ керамика на каждый корпус + один 470 мкФ электролит на входе («там электролит должен быть один»). У конденсаторов напряжение с запасом 2–3×.
11. База по ТЗ-2025: AT89S53; IDT7005 (символ именно 7005); 74AC573/КР1554ИР22,23 (так в ТЗ; ИР22 = аналог 74AC373, ИР23 = 374 — цоколёвка другая); 74HC173/74AC11873; IN74AC244/КР1554АП4 (так в ТЗ; АП4 = аналог 74AC241, аналог 244 — АП5); FYS-5612AX/BX; 74HC138/139; КД521А. Только КМОП (ТТЛ 74AS — ошибка). Timer2 и WDT не использовать.
12. Порты: P0, P2, P3.6/P3.7 — шина; P3.2/3.3 — INT; P1 — выходы (Y1 = P1.k, Y2 = P1.(k+1)); CS — P2.x по табл. 1.
13. Клавиатура: Col с регистра, Row через повторитель с Z; младшие биты шины (Col1 = бит 0), нумерация по рис. 4; диоды в столбцах; на строках подтяжка + последовательный R + C, 3·R·C ≥ 5 мс; программный антидребезг запрещён. [!] Не сканировать через дешифратор. [!] Последовательный R перед C обязателен — было замечание и допрос на защите. Принято у Осиповой: 2 кОм подтяжка, 10 кОм, 180 нФ.
14. Индикатор только через регистр (статика), R на каждый сегмент, ~360 Ом. ОК/ОА по варианту; a..g,dp = биты 0..7.
15. Не заводить в шину то, что сразу выходит. PSEN без ПЗУ не подключать; EA на VCC.
16. Регистры записи (Y2, индикатор, Col) — CS и WR через ИЛИ/ИЛИ-НЕ; повторитель Row — CS и RD. Полярность защёлки проверять по даташиту. Карту адресов просят проверить на защите.
17. Сброс ТЗ-2025 не требует, но R на GND без C не гарантирует сброс → RC (C от Vcc, R на GND), с кнопкой — ограничивающий R.

### A.1. УГО, второй эшелон
- Модель на поле не обязательна (в перечне есть); у Осиповой подписаны — прошло.
- Мелкая логика: входы слева, выходы справа.
- Пропорции: резистор 8(10)×4 мм, конденсатор 8×2, диод 6 мм/60°; поворот ±90°, надписи не поворачивать (ГОСТ 2.728, 2.730).
- Цифровые УГО — ГОСТ 2.743-91; память с доп. полями или без, но единообразно.
- Имена выводов тем же шрифтом, без индексов. Шрифт GOST type A. Меньше пересечений/изгибов. Раскладка листа — методичка Прил. А.

### A.2. Перечень (ПЭ3)
- КМ-1 — только микросхемы и разъёмы. В ПЗ1 — полный по ГОСТ 2.701 (графы 20/110/10/45, шапка 15, строка 8 мм).
- Порядок по алфавиту обозначений (C раньше R), группы с заголовками; однотипные подряд одной строкой «R2–R4 … 3».
- Своя основная надпись (форма 2/2а), код «ПЭ3».
- Тип + номинал (МЛТ-0,125 10 кОм; К10-17Б 68 нФ; К52-1Б 470 мкФ); у конденсаторов напряжение.
- Буквы приложений без З, О, Ч, Ё, Й, Ъ, Ы, Ь.

### A.3. Согласованность с ПЗ1
Номиналы на схеме = в перечне = в расчётах. Токи порта ≤ 10 мА. Уровни AT89S53 VOH ≈ 2,4 В vs VIH 74AC ≈ 3,15 В — стоит разобрать явно (P0 в режиме шины с активной подтяжкой).

## B. ПЗ1, ПЗ2, код

### B.1. Общее
Поля 2/2/2,5/1, TNR 12, одинарный; титул Прил. А, ПЗ2 по Прил. Б. Номер страницы внизу по центру. Формулы с новой строки, номер справа, сначала формула — потом числа, размерности. Из даташитов — только выдержки в приложение. Файлы «Фамилия ИО ПЗ1-v1.pdf», темы «МПС-ПЗ1/ПЗ2».

### B.2. ПЗ1
1. Структурная схема с обоснованием.
2. Функциональная схема с распределением ресурсов — [!] самое частое замечание.
3. Расчёты узлов: сегменты, клавиатура (подтяжка, R разряда, C, ток диода в худшем случае), сброс, кварц.
4. Карта адресов.
5. Временные диаграммы МК ↔ IDT7005 (ALE, P0, P2, RD/WR, CS; tAVLL, tRLRH).
6. Мощность.
7. Механизм доступа к буферу извне (правый порт, строб X2 → INT, указатели, BUSY).
8. Полный ПЭ3.
Замечания 2023: рисунок памяти, лишний электролит, полярность защёлки, PSEN без ПЗУ, CS/адрес, светодиоды через шину, точки ветвления, шрифт выводов, «не в такт», одинаковые номера у DD7.1/7.2. «Для начала схему до ума доведите».

### B.3. ПЗ2
Алгоритмы: инициализация (SP=07h), индикатор (0–9, 10='E', иначе выкл), Y1, Y2 со стробом, буфер, клавиатура (0–9, 'Т'=10, 'С'=11), обработчики. Таблица ошибок (dp, до нажатия, ≤ T3). Минимальное время заполнения при X1=0, максимальная глубина стека. В блок схемы алгоритма ОДИН вход; подпись «Схема алгоритма …»; листинг Courier 10. ГОСТ 19.701-90: условие — ромб, блоки по центру, одной ширины, линии не пересекаются, переход через соединитель.

### B.4. Код для робота
- Первая строка — ФИО, группа, вариант, версия.
- `DSEG AT 30h` / `CSEG AT 0h` / `sjmp START`; `nop`+`reti` на 03h,0Bh,13h,1Bh,23h; `org 2bh`; `START:`.
- `call Proc ; %proc%`, `jmp $ ; %stop%` в той же строке, без пробелов внутри `%…%`; в процедуре нет бесконечных циклов.
- Комментарии ≤ 250, имена ≤ 60; шапка у каждой процедуры; константы и MOVC-таблицы в конце, END.
- UTF-8 «Фамилия ИО-код-n.txt», тема «МПС-код», после рецензии ПЗ2. Минимум — ПЗ2 + программа 1.
- Стиль Михалина: EQU с говорящими именами (vars.inc).

## C. Банк вопросов защиты и КМ-4

### C.1. Общее
- Что делает МПС, блоки, виды схем (структурная / функциональная / Э3), начинать со структурной и функциональной.

### C.2. 8051 / AT89S53
- Гарвард, CISC, 8/16 бит; МЦ = 12 тактов = 1 мкс @12 МГц.
- 12 МГц: допустимо 0–24; RD/WR сотни нс ≫ tAA 7005. [!] «Собственная частота 12 МГц» — неверно.
- Конденсаторы кварца ~30 пФ по даташиту, не рассчитываются.
- EA: 1 — внутренняя Flash (12 КБ), 0 — внешняя; 12 В — программирование.
- Reset: порты FFh, PC=0, SP=07h, ОЗУ не чистится. P0 — открытый сток.
- Стек вверх. ОЗУ AT89S53 256 Б.
- PSW: CY, AC, F0, RS1, RS0, OV, P; Z нет. P1: 1 (слабая подтяжка) или 0, Z нет.
- Таймеры: режимы 0–3, загрузка 65536 − T·f/12.

### C.3. Шина и память
- MOVX: P2 — старший адрес, P0 — младший → 573 по ALE → данные, RD/WR. PSEN не вырабатывается.
- ПЗУ: MOVC + PSEN; ОЗУ: MOVX + RD/WR. [!] «Для ПЗУ WR, RD, PSEN» — неверно.
- Адрес устройства: его CS=0, остальные 1. `mov dptr,#ADR / movx @dptr,a`.
- Успевает ли МК: RD ~400 нс ≫ 55 нс.
- Кольцевой буфер: голова — куда писать, хвост — откуда читать; заполнено ((голова − хвост) mod N) + 1.

### C.4. Прерывания
- INT по уровню/срезу (ITx); у нас по спаду; по срезу флаг сбрасывается аппаратно.
- RETI дополнительно снимает «уровень обслуживается». [!] EA не трогает.
- Приоритеты: высокий прерывает низкий; при равных INT0, T0, INT1, T1, UART.
- Контекст: аппаратно только PC; `push acc` (не `push a`), psw, dpl/dph или смена банка.
- Прерывание от клавиатуры: все Col = 0 → нажатие → И строк → спад на INT → скан.

### C.5. Клавиатура
- Бегущий ноль; 244 в Z до CS&RD; диоды — чтобы не замкнуть 1 и 0 разных столбцов при двух нажатиях.
- 3RC ≥ Tдр; подтяжка держит 1; последовательный R ограничивает ток разряда. R1 ≈ 2 кОм ≤ R2 ≈ 10 кОм.
- Заряд через (R1+R2)·C, разряд через R2 и кнопку.

### C.6. Индикатор
- ОК: горит от 1, ОА: от 0. R = (Vcc − Useg − UOL)/Iseg → E24 (~330–360 Ом). ОК: все = 7Fh, «2» = 5Bh.

### C.7. Сброс, питание, электроника
- RST активен высоким, ≥ 2 МЦ, порог 0,7·Vcc. [!] Делитель из двух равных R даёт 2,5 В — не хватит.
- 68 нФ — ВЧ у корпуса; 470 мкФ — НЧ и запас. [!] В ДИСКИ наоборот — неверно.
- Висящие входы КМОП недопустимы; неиспользуемые выходы можно оставить.
- КМОП vs ТТЛ: статический ток ≈ 0, мощность ~ частоте. Уровни 74AC: VIL ≤ 1,35–1,5, VIH ≥ 3,15–3,5 В. AT89S53: VOL ≤ 0,45, VOH ≥ 2,4 В.

### C.8. Программирование
- ADD: CY, AC, OV, P; ADDC — 16-бит сложение; SUBB — сначала clr c. `jnb flag,$`. `mov c,P1.n / mov acc.0,c`.

### C.9. ГОСТ
- ГОСТ 2.743-91: шаг выводов 5 мм, основное поле ≥ 10 мм. [!] «1:1–3:1» — выдумка.
- ГОСТ 19.701-90: b = 1,5a.
- Перенос на другой лист — соединитель. ГОСТ на Э3 регламентирует R/C/VD, децимальные номера, шрифт.

### C.10. Тест КМ-4 — ловушки
- `addc A,#2` с решёткой; нет SPI/prescaler/трёх таймеров у i8051; АЦП по I2C/SPI программно — «Да»; SRAM в КР — по параллельной шине.
- Шина Т-образно с именем; пересечение — нет соединения; неиспользуемые входы к Gnd/Vcc.
- Примеры буфера: 30h–3Eh, 37/33 → 5; 30h–3Fh, 32/38 → 11; 40h–4Ah, 41/44 → 9; 40h–4Bh, 47/42 → 6.
- RC: τ ≈ Tдр/3.

## D. Что изменилось к ТЗ-2025

- Убраны UART, АЦП, светодиоды, Y3, второе знакоместо, обязательный узел сброса.
- Буфер развёрнут: внешнее устройство пишет X2 через правый порт, МК читает; указатели и флаги во внутреннем ОЗУ.
- Y2 = (M+X1+X2) mod 256 в регистр со стробом. Клавиатура 12 клавиш 4×3/3×4, индикатор FYS-5612.
- CS — линии P2.x; появились КД521А и повторитель 244; Timer2/WDT запрещены; фильтры 68 нФ + 470 мкФ.
- КМ-1 = схема + перечень микросхем; КМ-4 = тест; вместо одного листинга — 3 программы для робота.
- Методичка-2025: регистр индикатора обязателен, раздел про матричную клавиатуру и кольцевой буфер, Прил. А (раскладка А3), запрет программного антидребезга.
- Из старых работ переносимо: узлы клавиатуры/индикатора/защёлки, расчёты R/C, приёмы кода, подсчёт тактов, оформление.
