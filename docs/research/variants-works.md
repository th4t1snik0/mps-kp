## 3. Схемотехнические альтернативы под ТЗ-2025

Первая проверка — ТЗ-2025 (`docs/source/ТЗ-2025.pdf`, с. 5–6, табл. 1), вторая — указана в строке.

| Решение | Где | Верно под ТЗ-2025? | Проверка |
|---|---|---|---|
| Col с 74AC11873 вместо 74HC173 | Балашов, Базарнов | **Да** | ТЗ: «74ac11873 или 74hc173»; методичка рис. 8. Меняет ПЭ и ПЗ1 |
| Col прямо с P1 через диоды | Сорокина, Женюх, Базарнов, Сапрыкин | **Нет** | ТЗ п. 5: младшие биты шины; «P1 – выходы…»; методичка рис. 8 |
| Строки через регистр (ИР82, 11873, 173) | Козлова, Базарнов, Сапрыкин | **Нет** | ТЗ: повторитель in74ac244/кр1554ап4 в обязательном списке |
| Сброс: кнопка + RC | Балашов, Сорокина, Базарнов, ИАВ, Сапрыкин | **Да, по желанию** | ТЗ не требует; даташит AT89S53 (RST активен высоким); кнопку через ограничивающий R |
| CS через дешифратор 74HC138/ИД7 | Женюх, Егоров, Мерсов | **Нет** | Табл. 1 — каждый CS отдельной линией P2.x. **Расхождение:** ТЗ 2.1 п. 2 упоминает «дешифратор адресов» — вопрос руководителю |
| Строб записи = ИЛИ-НЕ(CS, WR), OE чтения = ИЛИ(CS, RD) | Козлова, Балашов, Иван | **Да** | независимо подтверждает решение из AGENTS |
| Защёлка КР580ИР82 | Балашов, Козлова, Женюх, Егоров | **Нет** | не КМОП, не из списка |
| 2 разряда индикатора, 595 | Сорокина, Женюх, Балашов, Гайворонский | **Нет** | ТЗ: один FYS-5612, статическая индикация через регистр |
| Индикатор DD/DA | Балашов, Базарнов, Иван | **Нет** | ГОСТ 2.710 — HG |
| RC на строках без последовательного R | Женюх, Сорокина, Козлова, Балашов, Базарнов | **Нет** | замечание на защите Женюха + методичка 3RC ≥ Tдр |
| Подтяжка + R + C на строку | Осипова (2 к/10 к/180 н), Иван | **Да** | приняты в 2025 |
| EA не подключён | Балашов | **Нет** | даташит: EA → VCC |
| Логика 1533/555/74AS | Балашов, Иван | **Нет** | ТЗ: КМОП |

| АЦП, UART, светодиоды, аналоговая земля, ПЗУ | Женюх, Козлова, Мерсов | **Нет** (не нужны) | `remarks-and-defense.md` D |

## 4. Предложение сабагента: 4 стиля по реальным примерам

| Стиль | Прототип | Что берём |
|---|---|---|
| **A. «Иван»** (сейчас) | Рязанцев, принята | Прил. А, американские вентили, KiCad 74xx, отводы 45° с именами, шины без имён, рамка с боковыми графами, «Сигнал/Вывод», номиналы по ГОСТ |
| **B. «Осипова»** | Осипова, ПРИНЯТО | та же раскладка; вентили ГОСТ; одна шина `BUS1`; 45°; «№/Цепь» или «Контакт/Цепь»; надписи клавиш; только штамп; отечественные названия в ПЭ |
| **C. «ГОСТ-учебник»** | Женюх + методичка Прил. А + «я за первый вариант» | ГОСТ 2.743 с полями; память с полями левый/правый порт; ромб 3-го состояния; шины B1…Bn, вход 90° с номером линии, имена только у глобальных; один XS1.1–XS1.3; `Ucc`; А3 |
| **D. «Пульт сверху»** | Балашов, Сорокина (статус ?) | клавиатура и индикатор сверху, МК и память снизу, разъёмы справа; вентили ГОСТ; шины BD/BA/BC, вход 90°; Col на 74AC11873; кнопка сброса через R; «Контакт/Цепь». Без квадратной памяти, ИР82, P1-столбцов |

Риски до реализации:
1. Имена на отводах: ⛔ у Рыженкова (2017), ✅ в 2025. Для C/D — «номер + имя только у глобальных», для A/B — как в принятых.
2. C и D опираются на «защищён со слов»/«?» — прямого подтверждения, что Михалин примет ГОСТ-поля и T-входы, нет; косвенно — «я за первый вариант», методичка Прил. А, «Типичные замечания». Лучше спросить.
3. Дешифратор CS — не использовать, пока руководитель не ответит (расхождение ТЗ 2.1 п. 2 и табл. 1).
4. Базарнов = Хромочкина: у соседей по группе должна отличаться хотя бы компоновка.
