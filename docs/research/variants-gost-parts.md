# Варианты оформления по ГОСТ и элементной базы из ТЗ (для 4 стилей листа Э3)

Собрано 2026-09-30 (сабагент). Источники: ТЗ-2025, методичка, лекции ч1 с. 10–11, «типовые замечания», замечания проверяющего у Женюха,
ответы КМ-4, даташиты из `docs/`, библиотеки KiCad 10 (`74xx`, `74xx_IEEE`), ГОСТ-библиотека группы; аналоги 1554 — справочники
[rlocman](https://www.rlocman.ru/comp/koz/adv/advh26.htm), [eham](https://www.eham.ru/articles/cifrovye-mikroshemy/3455-%D0%B0%D0%BD%D0%B0%D0%BB%D0%BE%D0%B3%D0%B8-%D0%BC%D0%B8%D0%BA%D1%80%D0%BE%D1%81%D1%85%D0%B5%D0%BC-%D1%81%D0%B5%D1%80%D0%B8%D0%B9-%D0%BA%D1%801533-%D0%B8-%D0%BA%D1%801554) (в строках ИД14 и ЛИ6 у eham ошибки).
Статусы: **2×** — два независимых источника; **1×** — один; **н/п** — знание ГОСТ «из головы», в материалах не найдено.

## 0. Найденные ошибки общей памяти

1. **КР1554ИР22 = аналог 74AC373, а не 573** (выходы 2, 5, 6, 9, 12, 15, 16, 19; входы 3, 4, 7, 8, 13, 14, 17, 18; EZ = 1, C = 11).
   Пин-в-пин 573 — КР1554ИР33 (нет в списке ТЗ). **2×**, перепроверено вручную — исправлено (`docs/changelog.md` 2026-09-30/11).
2. **КР1554АП4 = аналог 74AC241, а не 244**: у 241 вывод 19 (2OE) активен высоким. Аналог 244 — КР1554АП5. В ТЗ пара записана неточно. **2×**, исправлено там же.
3. **74AC11873 — сдвоенная 4-разрядная защёлка** (прозрачная по уровню LE, как 573), а не регистр по фронту, как 173. **2×** (даташит TI).
4. В KiCad 10 у `74xx_IEEE:7408` выходы вентилей 2–4 размечены как `input` — будет ERC; 2И в ГОСТ-виде рисовать своим символом. **1×**
5. В ГОСТ-библиотеке группы у `1564ИД7` вывод 3 подписан «A3», по даташиту `1554id7.pdf` — D2 (A2). **2×** (библиотеку группы мы не используем).

## 3. Что добавляет разнообразия без риска замечаний

**Безопасно:**
1. Разъёмы: «Сигнал/Вывод» ↔ ГОСТ «Цепь/Конт.» с обозначением X.
2. Земля/питание: метка GND ↔ ГОСТ-черта; питание мелочи в «Примечании» ↔ отдельной частью корпуса (один вариант на лист).
3. Метки выводов: латиница ↔ отечественные (C, EZ, ST, R, DI/DO); основное поле RG, BUF, RAM, CPU/MPU (не MCU).
4. IDT7005 с доп. полями ↔ без (руководитель — за поля).
5. Тип микросхемы на поле есть ↔ нет.
6. Раскладка блоков и номиналы (ГОСТ не касается).
7. Отечественные названия только с совпадающей цоколёвкой: 74HC02 → КР1554ЛЕ1, 74HC32 → ЛЛ1, 74HC11 → ЛИ3, 74HC21 → ЛИ6, IN74AC244 → КР1554**АП5**.
8. Конструктив с ИР23 для Y2 и индикатора: CLK = ИЛИ(CS, WR), −1 корпус, выход меняется строго после записи (защёлка ALE остаётся 573).
9. 74AC11873 вместо 173 — только целиком: LE = ИЛИ-НЕ(CSkb, WR), CLR ← ¬RST, вторая половина в «Примечании», свой символ.

**С риском (не брать или только явно выбранным стилем):**
- американские вентили и отводы 45° — принимались (Иван 2025), но методичка/лекция их не поддерживают, типовые замечания требуют Т-отводов;
- «ИР22» на символе 573 и «АП4» с 2OE активным нулём — ошибка цоколёвки, не стиль;
- 138/139 для стробов — почти без разнообразия, вопросы на защите; 138 для сканирования клавиатуры — прямо запрещён;
- нумерация построчно — противоречит типовым замечаниям;
- `74xx_IEEE:7408` — сломанные типы выводов.
