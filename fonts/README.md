# Шрифты

| Файл | Для чего | Лицензия |
| --- | --- | --- |
| `GOST_A.ttf` | рамки и надписи схемы Э3, схемы алгоритмов | как в исходной сборке шрифта «GOST type A» (свободно распространяемый) |
| `LiberationSans-Regular.ttf`, `LiberationSerif-Regular.ttf` | схемы алгоритмов (метрики Arial / Times New Roman) | SIL Open Font License 1.1 (liberation-fonts 2.1.5) |
| `Carlito-Regular.ttf` | схемы алгоритмов (метрики Calibri — как в Visio) | SIL Open Font License 1.1 |
| `PTSans-Regular.ttf` | схемы алгоритмов | SIL Open Font License 1.1 (ParaType) |

Шрифт для схем алгоритмов выбирается от ФИО студента (у группы рисунки не одинаковые), см. `internal/flow/style.go`.
