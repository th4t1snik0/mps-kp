# МПС ч.2 — курсовая и генератор под вариант

Общая база группы по курсовой «Разработка микропроцессорной системы на базе МК i8051»
(«Микропроцессорные системы ч.2», НИУ МЭИ, ИВТИ, кафедра ВМСС).

Вводишь группу и номер варианта M — получаешь:
- все параметры варианта (выводы, карта памяти, флаги, таймеры, какие 3 программы писать, ответы на п. 2.3 ТЗ);
- `vars.inc` — EQU/BIT для ассемблера;
- **схему Э3 на А3 с рамкой ГОСТ** (KiCad 10 + PDF + PNG), собранную под твой вариант: CS, INT и стробы
  на нужных выводах, клавиатура 4×3 или 3×4. ERC чистый, цепи проверены тестом.

> Таблица вариантов пока от **ТЗ-2025** (прошлый год). Новое ТЗ ещё не выдали — когда выдадут,
> добавится `data/table-<год>.yaml`.

## Как получить свой вариант

**Без установки (хоть с телефона):** вкладка **Actions** → **build** → **Run workflow** → группа (например `А-12`),
вариант M, **Фамилия И.О.** (в рамку), год набора (по умолчанию `23` → «А-12-23») → через несколько минут на странице
запуска появится **сводка: картинка схемы, ERC, параметры**. Всё раскладывается **по папкам «группа / вариант»**
(`А-12-23/14/…`) в ветке [**results**](../../tree/results) (открывается прямо на GitHub, там же оглавление)
и на Яндекс-диске (ниже).

**Локально:**

```sh
# macOS
brew install --cask kicad && brew install go poppler
# шрифт рамки: открыть fonts/GOST_A.ttf и установить

make try G=А-12 M=14 FIO="Рязанцев И.В."   # → build/А-12-23/14/
```

**Насовсем** — положи свой `students/<ник>/variant.yaml` (образец — `students/example-a12-14/`, там же ФИО
в рамку) и сделай PR: CI соберёт всех.

### Яндекс-диск

Джоба дублирует результаты в папку [MPS-SHEMAS](https://disk.yandex.ru/d/ai0wkudkDT9Tog):
`MPS-SHEMAS/<группа>/<вариант>/` (схема PNG/PDF/KiCad, `params.md`, `vars.inc`, ERC), недостающие папки создаёт сама.
Нужен OAuth-токен владельца папки в секрете репо `YADISK_TOKEN` (без него шаг пропускается):

1. https://oauth.yandex.ru/client/new → название любое → платформа «Веб-сервисы», Redirect URI
   `https://oauth.yandex.ru/verification_code` → права **Яндекс.Диск REST API**: «Чтение всего Диска»
   и «Запись в любом месте на Диске» → создать, скопировать **ClientID**.
2. Открыть `https://oauth.yandex.ru/authorize?response_type=token&client_id=<ClientID>` под своим аккаунтом,
   разрешить → скопировать токен.
3. GitHub → Settings → Secrets and variables → Actions → **New repository secret**: имя `YADISK_TOKEN`, значение — токен.
4. Другая папка — там же вкладка **Variables** → `YADISK_PUBLIC` = публичная ссылка на папку (папка должна быть опубликована).

Токен живёт ~год и даёт запись во весь Диск — держи на нём только учебное. В чужих форках секрет недоступен.

## Работа с ИИ

Правила для ИИ-ассистентов — в [AGENTS.md](AGENTS.md) и [RULES.md](RULES.md): важное в общей памяти
меняется только с доказательством и записью в [журнал](docs/changelog.md), любое утверждение проверяется дважды
(Claude Code читает AGENTS.md через `CLAUDE.md`, Cursor/Codex — напрямую). Коротко: числа варианта считает генератор,
итоги сессии — в `sessions/`, замечания и вопросы — в `notes/`, выжимки — в `docs/research/`.
Свои предпочтения («объясняй проще», «я знаю C») — в `CLAUDE.local.md`, он не коммитится.
